# Interview Preparation Kit

Standalone C++ solutions to interview-practice problems, including array rotation, minimum swaps, counting valleys, repeated strings, and two-dimensional arrays.

## Getting started

Compile the solution you want to run independently, for example `g++ -std=c++11 CountingValleys.cpp -o solution`. Supply the input expected by that problem.
